# Flowboard — канбан-доска

Учебное веб-приложение для управления задачами. Проект предназначен для демонстрации работы с DOM нативными средствами JavaScript без библиотек и фреймворков.


## Возможности

- создание, редактирование и удаление задач;
- распределение задач по трём статусам;
- изменение статуса с помощью Drag and Drop;
- несколько независимых досок;
- чек-листы, теги, поиск, фильтрация и сортировка;
- повторяющиеся задачи, архив и отмена действий;
- импорт и экспорт резервных копий;
- статистика, недельный график и семь тем оформления;
- интерфейс на русском, игбо, английском, узбекском, украинском, иврите и идише;
- горячие клавиши и клавиатурное перемещение карточек;
- календарь и таймлайн дедлайнов;
- зависимости между задачами и настраиваемые колонки;
- исполнители, комментарии и журнал изменений;
- аккаунты, роли команды, упоминания и уведомления;
- несколько изолированных рабочих пространств и права на уровне досок;
- 2FA/TOTP, Passkeys (WebAuthn), подтверждение email и журнал аудита;
- push-уведомления, GitHub webhooks и календарная лента iCalendar;
- пользовательские поля, публичные представления и формы сбора задач;
- долговечный журнал операций совместного редактирования;
- встроенный помощник для чек-листов, сводок, приоритетов и загрузки;
- присутствие участников и совместные realtime-черновики;
- приглашения, восстановление пароля и управление активными сессиями;
- центр уведомлений, ветки обсуждений, реакции и наблюдатели задач;
- цели, контрольные точки, дорожная карта и отчёт по загрузке;
- шаблоны, цветные карточки и эмодзи-обложки;
- Pomodoro, расширенные отчёты и напоминания;
- командная палитра и пакетные операции с задачами;
- оценка и учёт затраченного времени;
- локальные вложения и автоматические правила задач;
- переносимый пакет синхронизации и синхронизация между вкладками;
- PWA-режим с офлайн-кэшем;
- настройки контрастности, размера текста и уменьшения анимаций;
- сохранение данных в `localStorage`.

Данные сохраняются локально в браузере, поэтому задачи остаются на доске после перезагрузки страницы.

В каталоге `backend/` находится REST API на FastAPI с SQLite, авторизацией,
ролями, realtime-синхронизацией, историей версий, поиском, уведомлениями,
API-токенами, webhooks, очередью фоновых задач, WebAuthn/Web Push и безопасными файловыми
вложениями. Frontend подключается к нему
после явной настройки адреса и автоматически откатывается на `localStorage`. Инструкции запуска —
в `backend/README.md`.

## Технологии

- HTML5;
- CSS3;
- JavaScript и ES-модули;
- нативный DOM API;
- Drag and Drop API;
- Web Storage API;
- Python 3.11+;
- FastAPI и Pydantic;
- SQLite для локальной разработки и PostgreSQL для production.

## Локальный запуск

Запустите проект через локальный сервер, например:

```bash
python3 -m http.server 4173
```

Затем откройте `http://localhost:4173`. Порт `8000` остаётся свободным для
FastAPI.

## Автотесты

Проект использует встроенный тестовый раннер Node.js, поэтому установка зависимостей не требуется.

```bash
npm test
```

Дополнительные режимы:

```bash
npm run test:watch
npm run test:coverage
npm run test:e2e
npm run test:all
```

Unit-тесты проверяют CRUD-операции, доски, сортировку, повторения, фильтры,
состояние, `localStorage` и статистику. Playwright E2E-тесты проходят реальные
сценарии интерфейса: создание и архивацию задач, undo, темы, горячие клавиши,
импорт и экспорт.
